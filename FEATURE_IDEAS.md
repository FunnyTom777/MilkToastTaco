## Index:

`🟪 wip` - Work In Progress, feature is still in progress.

`🟦 od` _Outdated_ - Feature idea is outdated, needs updating, or has been superseded.

`🟫 ac` _Archived_ - Feature is archived and is not updated.

`🟥 ni` _needs issue_. - A issue should be opened dedicated to this feature.

`🟨 hp` _High Priority_ - Feature is high priority and should be implemented soon.

`🟩 lp` _Low Priority_ - Feature is low priority and more high priortiy issues should be prioritized.

`🟧 lt` _Long Term_ - a Long term feature, not to be implemented right away, reqires long term development to be completed.

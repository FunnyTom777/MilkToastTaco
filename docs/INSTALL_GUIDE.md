# Install Guide — Milk Toast Taco

> **Windows only for now.** On Mac or Linux you'll have to work it out yourself — on Linux you probably already know your way around Python anyway. 😄

## 1. Install Python

You need **Python 3.11 or newer**.

- Download it from [python.org/downloads](https://www.python.org/downloads) if you don't have it.
- Check yours with:

```text
python --version
```

## 2. Download Milk Toast Taco

1. Go to the top of the [MilkToastTaco GitHub page](https://github.com/FunnyTom777/MilkToastTaco).
2. Click the big green **Code** button.
3. At the very bottom of the dropdown, click **Download ZIP**.
4. Save it somewhere easy to find — Desktop or Documents is fine. It'll be called something like `MilkToastTaco-main.zip`.

## 3. Extract the ZIP

1. Open File Explorer and find `MilkToastTaco-main.zip`.
2. Right-click it and choose **Extract All**.
3. Click **Extract**.
4. Open the new folder it creates.

## 4. Run it

1. Right-click empty space inside the folder and choose **Open in Terminal**.
2. Type:

```text
python main.py
```

3. Hit **Enter** — the MTT launcher should pop up!

**You're all done! 🎉**

> **Trouble?** If you get `Python was not found`, Python either isn't installed correctly or isn't on your PATH. Google the exact error and you'll find a fix. 😄

Milk Toast Taco is a heavily work-in-progress Python simulation thing, with no definitive goal yet. Think Dwarf Fortress-style ideas and Farming Sim inspiration, after about 3 years of engine-shopping right back to Python. Mostly not playable in its current state — but feel free to poke around.

Try it anyway (if you're brave)

Windows + Python 3.11+, download the ZIP, run python main.py and the launcher should pop up. Don't expect much yet — it's early, broken in places, and very much still being figured out.
